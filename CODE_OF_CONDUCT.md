# Code of Conduct

We want participation in the David Uhden Collado Website project to be respectful, constructive, and welcoming to people with different backgrounds and levels of experience.

## Expected behavior

- Treat other participants with courtesy and respect.
- Discuss code and ideas in good faith and respond constructively to feedback.
- Focus criticism on the work rather than the person.
- Respect differing identities, perspectives, and experience levels.
- Keep issues, reviews, and project discussions relevant and considerate.

## Unacceptable behavior

Harassment, discrimination, hateful language, personal attacks, threats, intimidation, unwanted sexual attention, sharing private information without consent, and sustained disruptive behavior are not acceptable. These expectations apply to issues, pull requests, reviews, and project-related public spaces.

## Reporting and response

Raise non-sensitive project concerns through a GitHub issue or pull request. For a private or sensitive report, email [david@uhden.dev](mailto:david@uhden.dev), which is published on the website. Include relevant context, and avoid sharing private information in a public report.

Maintainers will review reports as promptly as practical, handle them discreetly, and take proportionate action. This may include a request to stop, removal of content, temporary restrictions, or exclusion from project spaces. Retaliation against someone who reports a concern in good faith is unacceptable.

This code applies in project spaces and when a person is representing the project in public.
